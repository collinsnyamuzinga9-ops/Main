# Prime Systems Website

Responsive static website for Prime Systems, an IT services business in Zimbabwe.

## Open in VS Code

Open this repository folder in VS Code. Open `index.html` to view the homepage, or `contacts.html` for the contacts directory. The `.vscode` launch configuration opens the homepage in Microsoft Edge.

The site uses plain HTML and CSS; no build step is required. It includes `index.html`, `about.html`, `services.html`, `gallery.html`, `booking.html`, and `contacts.html`, with shared styles in `styles.css` and images in `images/`.

Before using the forms or publishing as a production service, confirm the contact details and team information and connect the booking form to a service that can receive submissions. The included forms may only demonstrate the front end.
